# FastAPI Auth Project

This project has been scaffolded with a modular FastAPI structure for authentication.

## Structure

- app/main.py: application entry point
- app/config.py: environment configuration
- app/database.py: SQLAlchemy engine and session
- app/models/: SQLAlchemy models
- app/schemas/: Pydantic schemas
- app/routers/: API endpoints
- app/services/: business logic
- app/auth/: authentication helpers
- app/dependencies/: shared dependencies
- app/middleware/: middleware utilities
- app/exceptions/: exception handlers
- app/utils/: constants and helpers

## Run

```bash
pip install -r requirements.txt
python run.py
```
